# sec-vault

## Structure

```text
sec-vault/
├── ctf/              # CTF event writeups categorized by year & event
├── labs/             # Walkthroughs & notes (TryHackMe, Hack The Box, etc.)
└── certifications/   # Study notes, lab prep, and exam reviews
```
